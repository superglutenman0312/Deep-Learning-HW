# Deep Learning Course Projects 🧠🤖

This repository contains the assignments and projects developed during the **Deep Learning** course.
The projects range from basic image processing to advanced computer vision and reinforcement learning applications.

## 📚 Projects Overview

| Assignment | Topic | Description | Key Tech |
| :--- | :--- | :--- | :--- |
| [**HW1**](./HW1) | **Python & Image Basics** | A warm-up project focusing on **Python programming** logic and **basic image processing** techniques (filtering, transformation). | NumPy, OpenCV |
| [**HW2**](./HW2) | **Weather Recognition** | Built a CNN model to classify weather conditions into **4 classes**: `Rain`, `Cloudy`, `Shine`, and `Sunrise`. | PyTorch, CNN |
| [**HW3**](./HW3) | **Food Classification** | Large-scale image classification on a dataset of **100,000 images** covering **50 different school lunch classes**. | ResNet, Data Augmentation |
| [**HW4**](./HW4) | **RL for Super Mario** | Implemented **Reinforcement Learning (RL)** algorithms to train an AI agent to play **Super Mario Bros** autonomously. | RL (PPO/DQN), Gym |

## 📂 Detailed Resources

For more in-depth details on implementation, experiments, and results, please navigate to each assignment's folder.
Each directory contains:
* 💻 **Source Code** (`.ipynb`, `.py`)
* 📄 **Project Reports** (`.pdf`, `.ppt`)
* 🎥 **Demo Videos** (only HW4 has)

## 🛠️ Tech Stack
* **Languages**: Python 3
* **Deep Learning Frameworks**: PyTorch
* **Libraries**: NumPy, Pandas, Matplotlib, OpenCV, OpenAI Gym (for Mario)
