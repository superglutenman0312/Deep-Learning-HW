# HW1: Image Classification with Deep Learning

## 📝 Assignment Objective
The goal of this assignment is to implement a Deep Learning model to perform **Image Classification**.
The task involves:
1.  **Data Preprocessing**: Loading and normalizing the dataset.
2.  **Model Architecture**: Designing a Convolutional Neural Network (CNN) from scratch or finetuning a pre-trained model (e.g., ResNet).
3.  **Training Loop**: Implementing forward pass, loss calculation, and backpropagation.
4.  **Evaluation**: Measuring accuracy and visualizing the loss curve.

## 📂 Files
* `n26130825_王郁誠_HW1.ipynb`: The main Jupyter Notebook containing the training code and analysis.

## 🛠️ Implementation Details
* **Dataset**: MNIST
* **Framework**: PyTorch
* **Model**: Simple CNN
* **Optimizer**: Adam
* **Loss Function**: CrossEntropyLoss
